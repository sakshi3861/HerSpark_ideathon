# SurakshaShield Web Security Suite

React and Vite application containing the SurakshaShield and CycleSafe screens.

## Development

```sh
npm install
npm run dev
```

## Routes

- `/` — SurakshaShield overview
- `/cyclesafe/welcome` — CycleSafe consent setup
- `/cyclesafe/login` — CycleSafe PIN and duress login
- `/cyclesafe/home` — CycleSafe dashboard
- `/console` — Console overview
- `/console/live-traffic` — Live traffic inspector
- `/console/audit-ledger` — Audit ledger
- `/registry` — Verified registry
